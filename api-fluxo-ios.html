Fluxo de funcionamento de API no iOS

Mapa detalhado com os principais termos usados no ciclo de rede de um app iOS moderno (UIKit ou SwiftUI).

URLSession Async/Await Codable Repository ViewModel Main Thread Core Data Keychain Feature Flag

1) Fluxo operacional (detalhado)

flowchart TD
  A[Usuário interage com a tela\nView / ViewController] --> B[ViewModel recebe evento]
  B --> C{Feature Flag ativa?\n(UserDefaults / Remote Config)}
  C -- Não --> X[Fluxo alternativo/local\nSem chamada remota]
  C -- Sim --> D[Repository monta caso de uso]

  D --> E[Request Builder\nURL + Method + Headers]
  E --> F[Auth Interceptor\nBearer Token do Keychain]
  F --> G[URLSession.data(for:)\nAsync/Await]

  G --> H{HTTP Status Code}
  H -- 2xx --> I[Decode JSON com Codable]
  I --> J[DTO -> Domain Model Mapper]
  J --> K[Persistência opcional\nCore Data / Cache em memória]
  K --> L[ViewModel atualiza State]
  L --> M[UI renderiza na Main Thread]

  H -- 401 --> N[Refresh Token\nAuth Service]
  N --> F

  H -- 4xx / 5xx --> O[Mapeia erro de rede\npara erro de domínio]
  O --> P[Retry/Backoff quando aplicável]
  P --> Q[Exibe fallback amigável\n+ Telemetria/Logs]

  class A,B,D,E,F,G,I,J,K,L,M io;
  class C,H warn;
  class N,X ok;
  class O,P,Q err;
