# Curso iOS — Guia de termos e fluxo de trabalho

Este projeto foi criado para servir como um guia inicial de termos e expressões usados no dia a dia da área de tecnologia, com foco especial em desenvolvedores iOS.

O objetivo principal é facilitar a aprendizagem de vocabulário técnico, promover familiaridade com conceitos comuns de desenvolvimento mobile e apoiar a compreensão do fluxo de trabalho profissional em projetos reais.

## 🚀 Site publicado

Acesse o projeto em produção no GitHub Pages:

https://uellissonlopes.github.io/curso-ios/

## 📌 Sobre o projeto

O material reúne:

- termos e conceitos de iOS e Swift
- termos de arquitetura, UI, networking, persistência e Git
- exemplos práticos de uso
- pronúncia de termos em inglês
- fluxo de trabalho do desenvolvedor com Jira, Git e Devin

## ✨ Funcionalidades

- busca por termo
- filtro por categoria
- ordenação alfabética
- modo de leitura com foco em acessibilidade
- exibição de exemplos
- reprodução de pronúncia por voz do navegador
- página com fluxograma visual do processo de desenvolvimento

## 🧩 Páginas do projeto

- `index.html` — guia principal com termos e conceitos
- `fluxo-trabalho.html` — fluxograma do processo de desenvolvimento
- `api-fluxo-ios.html` — material complementar relacionado ao fluxo iOS

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Mermaid para diagramas
- API nativa de síntese de voz do navegador

## ▶️ Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/uellissonlopes/curso-ios.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd curso-ios
   ```
3. Abra `index.html` no navegador ou utilize um servidor local simples.

## 📚 Objetivo educacional

Este projeto foi pensado como um material de apoio inicial para quem está começando na área de tecnologia e deseja conhecer melhor o vocabulário e os processos usados no desenvolvimento iOS e em contextos de trabalho colaborativo.
